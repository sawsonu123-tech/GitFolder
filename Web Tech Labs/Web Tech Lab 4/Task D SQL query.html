Students sorted by course SELECT s.student_id, s.student_name, c.course_name FROM student s JOIN course c ON s.course_id = c.course_id ORDER BY c.course_name; 🧠 What it does: Joins student + course Sorts students based on course name (A → Z) ✅ 2. Students in a semester SELECT * FROM student WHERE semester = 3; 🧠 What it does: Shows all students in semester 3 👉 You can change 3 → any semester ✅ 3. Total students count SELECT COUNT(*) AS total_students FROM student; 🧠 What it does: Counts total number of students in table ✅ 4. Count per course SELECT c.course_name, COUNT(s.student_id) AS total_students FROM student s JOIN course c ON s.course_id = c.course_id GROUP BY c.course_name; 🧠 What it does: Groups students by course Shows how many students in each course 🔥 Example Output (for understanding) course_name total_students BCA 5 MCA 3 ⚠️ Important exam tips Use JOIN when course name is needed Use GROUP BY for counting per category Use COUNT() for totals 🧠 Final understanding Query Type Concept Sorting ORDER BY Filtering WHERE Counting COUNT() Grouping GROUP BY 🚀 If examiner asks extra You can also say: 👉 “We can combine filtering + grouping like:” SELECT course_id, COUNT(*) FROM student WHERE semester = 3 GROUP BY course_id; If you want, I can: Convert these into PHP pages (buttons + output) Or give viva questions + answers 🔥
